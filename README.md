# Ilias Login (UFR aka. ALU)

This is a repository for a **firefox** addon which clicks you through the Ilias and campus pages automatically.
The Extension will only work for the Albert-Ludwigs-Universität in Freiburg, Germany.
You need to have your password saved by the firefox password manager.
