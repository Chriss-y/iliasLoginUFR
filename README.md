# Ilias Login (UFR aka. ALU)

This is a repository for a **firefox** addon which clicks you through the Ilias and campus pages automatically.
The Extension will only work for the Albert-Ludwigs-Universität in Freiburg, Germany.
You need to have your password saved by the firefox password manager.

## Installation

- [iliasLoginUFR](https://addons.mozilla.org/addon/iliasloginufr/): In the Firefox add-on store.
- [iliasLoginUFRgit](https://github.com/Chriss-y/iliasLoginUFR/releases): opening the Github release `.xpi` file with Firefox.
  
For now both should automatically update themselves. (I might delete one version eventually)
